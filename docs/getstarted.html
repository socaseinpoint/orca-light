§ get started — install · init · use cases

Один симлинк. Без демона. Поехали. One symlink. No daemon. Let's go.

orca — один Python-скрипт. Ставится в любой git-репо за минуту, стейт живёт в .orca/ вместе с кодом. orca is a single Python script. Drops into any git repo in a minute; state lives in .orca/ alongside your code.

§ 01

Установка и первый focusInstall and your first focus

Шесть шагов от нуля до проверяемого хэндоффа.Six steps from zero to a verifiable handoff.
01

Бинарь на PATHBinary on your PATH

Клонируй и слинкуй. Глобальный — один симлинк, как git. Ноль глобального стейта.Clone and symlink. Global — one symlink, like git. Zero global state.
git clone https://github.com/socaseinpoint/orca-light.git
ln -s "$PWD/orca-light/bin/orca" ~/.local/bin/orca   # ~/.local/bin on PATH
orca --help          # sanity check
command -v orca      # prints the symlink path
02

Инициализируй в проектеInitialize in a project

Из корня любого git-репо. Создаёт .orca/ — одна папка, коммитится с кодом, continuity путешествует с репо.From the root of any git repo. Scaffolds .orca/ — one folder, committed with your code, continuity travels with the repo.
cd ~/code/my-project
orca init
03

Заведи первый focusCreate your first focus

Папка + focus.md: зачем кампания (intent), когда готово (done-when), ориентация (Now), пустой Trail.A folder + focus.md: why the campaign exists (intent), when it's done (done-when), orientation (Now), an empty Trail.
mkdir -p .orca/01-login-bug/arks
$EDITOR .orca/01-login-bug/focus.md   # intent / done-when / Now / Trail
04

Подключи resume-skillWire the resume skill

Скопируй skill в Claude Code — тогда на входе в сессию работает /orca-resume.Copy the skill into Claude Code — then /orca-resume works at session start.
cp -r orca-light/skills/orca-resume ~/.claude/skills/
05

Хуки (опционально)Hooks (optional)

Три read-only хука: SessionStart инжектит orca now, Stop предупреждает если якоря не держат, PreCompact флашит «почему» перед компакцией. Вставь в ~/.claude/settings.json (/config), заменив ORCA_LIGHT на путь репо.Three read-only hooks: SessionStart injects orca now, Stop warns if anchors don't hold, PreCompact flushes the "why" before compaction. Paste into ~/.claude/settings.json (/config), replacing ORCA_LIGHT with the repo path.
"SessionStart": [{ "hooks": [{ "type": "command",
  "command": "ORCA_LIGHT/hooks/session-start.sh" }] }]
06

Работай. Доверяй якорям.Work. Trust the anchors.

Дописывай Trail по ходу, orca verify доказывает хэндофф, orca done закрывает. На следующей сессии — /orca-resume.Append to the Trail as you go, orca verify proves the handoff, orca done closes it. Next session — /orca-resume.
orca now             # where am I?
orca verify          # prove the latest handoff
orca done login-bug  # move it to done/
§ 02

Три кейса, где это окупается.Three cases where it pays off.

Не про «ещё один трекер». Про то, чтобы холодный возврат был дешёвым.Not "another tracker." About making the cold return cheap.
case 01 фича на много днейmulti-day feature

Большая задача, которую не закрыть за разA big task you can't finish in one sitting

Строишь фичу неделю, по часу в день. Каждое утро — «так, на чём я остановился». orca-resume читает прошлый транскрипт + git log и выдаёт ре-ориентацию на один экран: проблема · сделано · что изменилось · следующий шаг.You build a feature over a week, an hour a day. Every morning — "wait, where was I?" orca-resume reads the prior transcript + git log and hands back a one-screen re-orientation: problem · done · what changed · next step.

/orca-resume
case 02 дебаг через сессииdebugging across sessions

Баг, который не влез в одну сессиюA bug that didn't fit one session

Сужаешь гипотезы, упираешься в стенку, закрываешь ноут. Самое ценное — не «что сделал», а что было в голове: какие версии отвёл, что подозреваешь. Слой head: держит этот хрупкий поток до завтра.You narrow hypotheses, hit a wall, close the laptop. The valuable part isn't "what I did" but what was in your head: which theories you ruled out, what you suspect. The head: layer keeps that fragile thread till tomorrow.

head: гипотезы в полётеhypotheses in flight
case 03 параллельная работаparallel work

Несколько focus'ов и окон Claude разомSeveral focuses and Claude windows at once

Две сессии на разных арках в одном репо. Наивный resume свернул бы живой транскрипт и побил continuity. Live-aware, set-based resume знает, какие транскрипты безопасны — живую параллельную пропускает, множество сворачивает ровно один раз.Two sessions on different arks in one repo. A naive resume would fold a live transcript and corrupt continuity. The live-aware, set-based resume knows which transcripts are safe — it skips the live parallel one and folds the set exactly once.

Запусти рядом с коромRun it alongside the core

Сканит .orca/ по проектам, рисует карту, таймлайн сессии и реестр side-effects. Реактивно через SSE. Только читает — ничего не пишет, test:-якоря не исполняет. Корень сканирования — ORCA_SCAN_ROOT.Scans .orca/ across projects, draws the map, the session timeline, and the side-effects index. Reactive over SSE. Read-only — writes nothing, never runs a test: anchor. Scan root via ORCA_SCAN_ROOT.
cd orca-light/dashboard
npm install
npm run dev          # open the printed localhost URL

Поставил за минуту — доверяешь годами.Installed in a minute — trusted for years.

Открытый код, ноль глобального стейта, ничего не висит фоном. Это просто файлы в твоём репо.Open source, zero global state, nothing running in the background. It's just files in your repo.
